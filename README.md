# Awesome Fn Button

macOS-приложение, которое освобождает клавишу **Fn / 🌐** от конфликтующих системных назначений и оставляет на одиночное нажатие только **смену языка ввода**.

Цель — убрать ситуации, когда вместо переключения раскладки появляются эмодзи, запускается диктовка или нажатие воспринимается как «залипшее».

**Статус:** описание и требования к проекту. Приложение ещё не реализовано; этот репозиторий пока не меняет настройки Mac.

## Как должно работать

1. Пользователь открывает приложение; оно проверяет настройки Fn и наличие хотя бы двух источников ввода.
2. Приложение показывает найденные конфликты и список предстоящих изменений.
3. По кнопке «Оставить только смену языка» приложение сохраняет исходные значения и автоматически применяет настройки.
4. Одиночное нажатие Fn переключает язык; конфликтующие назначения Fn отключены везде, где macOS позволяет это сделать.
5. Приложение проверяет сохранённые значения и сообщает, если для вступления изменений в силу требуется дополнительное действие.
6. Кнопка «Восстановить» возвращает изменённые приложением настройки к исходным значениям.

После применения настроек приложение можно закрыть. Постоянная работа в фоне не планируется для первой версии.

## Что приложение должно настраивать

- Назначение одиночного нажатия Fn / 🌐 — «Сменить источник ввода».
- Вызов эмодзи и символов через Fn — убрать как альтернативное назначение одиночного нажатия.
- Вызов диктовки через Fn, включая двойное нажатие, — отключать при обнаружении такого назначения.
- Сочетания Siri и другие доступные системные сочетания с Fn — находить и отключать, если они конфликтуют с выбранным режимом.
- Остальные горячие клавиши и способы вызова этих функций — сохранять.

В первой версии настройка выполняется явно по кнопке. Приложение должно показывать неподдерживаемые настройки, а не сообщать об успешном отключении без проверки.

## Ограничения

- Fn одновременно служит модификатором и, на некоторых клавиатурах, клавишей Globe. Не все её функции управляются одной системной настройкой.
- Полное отключение всех сочетаний Fn нельзя обещать до проверки на поддерживаемых версиях macOS и реальном оборудовании.
- Изменение настроек не гарантирует исправления ошибок macOS, аппаратного залипания или задержек, вызванных сторонними программами.
- Сторонние переназначения, например в Karabiner-Elements или приложениях диктовки, требуют отдельной диагностики. Первая версия не должна молча менять их конфигурацию.
- Для переключения языка пользователь должен добавить не менее двух источников ввода. Приложение не должно самостоятельно удалять или заменять раскладки.

## План реализации

- [ ] Нативное приложение на Swift / SwiftUI.
- [ ] Диагностика назначений Fn без изменения настроек.
- [ ] Проверка способов изменения настроек и матрица поддерживаемых версий macOS.
- [ ] Сохранение исходных значений перед первым изменением, включая отсутствие настройки.
- [ ] Применение изменений с проверкой результата и обработкой частичного сбоя.
- [ ] Восстановление только затронутых настроек без перезаписи посторонних изменений.
- [ ] Проверка одиночного, двойного и длительного нажатия Fn, а также сна и пробуждения Mac.
- [ ] Проверка на встроенной клавиатуре MacBook и внешней Apple-клавиатуре.
- [ ] Подписанная и нотарифицированная сборка для установки.
